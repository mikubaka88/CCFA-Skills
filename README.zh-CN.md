当前版本为 **0.12.1**。这次把写作前的材料准备与修改后的检查连起来：带着全文主线、必要邻段和合适原文改稿，再检查变化影响的论点。独立领域审读沿用现有“独立复核”开关，先看稿件，再由主审合并发现。主文档介绍了用法；日月配置台附有实际界面和配置例子，额外投入仍由现有开关决定。

2026-10-20 补充了明确请求下的自主科研循环：提出假设、运行实验、读取结果并决定下一步。使用方式、预算与执行边界见[自主科研说明](ccf-pipeline-orchestrator/references/autonomous-research.md)。

0.12.1 另增默认关闭的红色「结果待填成稿」开关：先写连贯初稿与条件式分析，结果后续填写；可能出现些许幻觉，写完自动检查整稿一致性。安装恢复、图层对齐和科研最终评测状态也已修复，写作上下文裁剪规则保持不变。
