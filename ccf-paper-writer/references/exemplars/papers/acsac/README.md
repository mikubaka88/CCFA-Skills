# Computer security reference papers

## CoBBL: Dynamic Constraint Generation for SNARKs

IEEE S&P 2025 · Distinguished Paper

Kunming Jiang, Fraser Brown, Riad Wahby

Start with the abstract and the motivation for dynamically generated constraints. Examine how the paper relates expressiveness, proof construction costs, and experimental workloads.

[Program or award](https://www.sp2025.ieee-security.org/awards.html) · [Proceedings](https://www.ieee-security.org/TC/SP2025/accepted-papers.html) · [Paper](https://eprint.iacr.org/2025/1849)

## Amplification by Shuffling without Shuffling

ACM CCS 2023 · Distinguished Paper

Borja Balle, James Bell, Adrià Gascón

Use the abstract and problem formulation to compare the privacy guarantee with the mechanism normally used to obtain it. State the threat model and privacy assumptions before generalizing.

[Program or award](https://www.sigsac.org/ccs/CCS_awards/ccs-bestpaper.html) · [Proceedings](https://doi.org/10.1145/3576915.3623215) · [Paper](https://arxiv.org/abs/2305.10867)

## Blindfold: Confidential Memory Management by Untrusted Operating System

NDSS 2025 · Distinguished Paper

Caihua Li, Seung-seob Lee, Lin Zhong

Start with the threat model and design boundary. Trace what the operating system is still allowed to manage and what data access is controlled, then read the cost and functional coverage evidence.

[Program or award](https://www.ndss-symposium.org/wp-content/uploads/NDSS-2025-Awards-NDSS2026.pdf) · [Proceedings](https://www.ndss-symposium.org/ndss-paper/blindfold-confidential-memory-management-by-untrusted-operating-system/) · [Paper](https://www.ndss-symposium.org/wp-content/uploads/2025-294-paper.pdf)
