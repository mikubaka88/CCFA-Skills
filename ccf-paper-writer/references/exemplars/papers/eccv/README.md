# Computer vision reference papers

## Unsupervised Learning of Probably Symmetric Deformable 3D Objects from Images in the Wild

CVPR 2020 · Best Paper

Shangzhe Wu, Christian Rupprecht, Andrea Vedaldi

Inspect Figure 1 and the method opening. Note how the paper converts the lack of 3D supervision into a set of image-generation factors and treats symmetry as an empirical regularity with exceptions.

## SinGAN: Learning a Generative Model from a Single Natural Image

ICCV 2019 · Best Paper (Marr Prize)

Tamar Rott Shaham, Tali Dekel, Tomer Michaeli

Compare the abstract with the multiscale architecture figure. Track how a single-image training setup is paired with distinct qualitative tasks and how the purpose of the pyramid is explained.

[Program or award](https://www.thecvf.com/?page_id=413) · [Proceedings](https://openaccess.thecvf.com/content_ICCV_2019/html/Shaham_SinGAN_Learning_a_Generative_Model_From_a_Single_Natural_Image_ICCV_2019_paper.html) · [Paper](https://openaccess.thecvf.com/content_ICCV_2019/papers/Shaham_SinGAN_Learning_a_Generative_Model_From_a_Single_Natural_Image_ICCV_2019_paper.pdf)

Jeremy Klotz, Shree K. Nayar
