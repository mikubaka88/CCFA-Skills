# Computer networking reference papers

## Routing on Multiple Optimality Criteria

SIGCOMM 2020 · Best Paper

João Luís Sobrinho, Miguel Alves Ferreira

Read the introduction's choice of multiple criteria before the main definitions. Locate the condition that connects route selection objectives and the proposed routing approach.

[Program or award](https://www.sigcomm.org/awards/best-paper-award) · [Proceedings](https://doi.org/10.1145/3387514.3405864) · [Paper](https://www.lx.it.pt/~jls/publications_ficheiros/RoutingMultipleOptimalCriteria.pdf)

## RF-Based 3D SLAM Rivaling Vision Approaches

MobiCom 2025 · Main-conference talk and Best Artifact Award

Haowen Lai, Zhiwei Zheng, Mingmin Zhao

Read the sensing challenges and evaluation comparison. Separate the evidence for 3D reconstruction from the claim about operation in conditions that challenge visual sensing. The artifact award is recorded separately from the technical talk.

[Program or award](https://www.sigmobile.org/mobicom/2025/program.html) · [Proceedings](https://www.sigmobile.org/mobicom/2025/accepted.html) · [Paper](https://waves.seas.upenn.edu/projects/cartoradar/)

## Scheduling Stochastic Traffic With End-to-End Deadlines in Multi-hop Wireless Networks

INFOCOM 2024 · Best Paper

Christos Tsanikidis, Javad Ghaderi

Start with the model and theorem statement. Keep stochastic arrival assumptions, scheduling constraints, deadline objective, and the performance guarantee distinct.

[Program or award](https://www.ee.columbia.edu/news/ee-prof-javad-ghaderi-and-phd-student-christos-tsanikidis-win-best-paper-award-ieee-infocom) · [Proceedings](https://www.ee.columbia.edu/~jghaderi/infocom24.pdf)
