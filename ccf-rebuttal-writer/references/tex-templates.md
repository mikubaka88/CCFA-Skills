# TeX Templates

Use this file when the requested or established output is a rebuttal TeX file, author-response TeX, or response-letter template. A full multi-reviewer response can remain plain text or use the user's supplied form.

## Default Selection

Use `assets/templates/default-general-common-reviewer.tex` when a full TeX rebuttal needs shared and reviewer-specific responses. Preserve a supplied venue template. The general template contains:

- `General Response`
- `Common Concerns`
- `Reviewer-Specific Clarifications`

Use only sections that fit the actual reviews. The overview answers the decisive concern; a positive opening is optional and must reflect actual reviewer statements or supplied evidence.

## Template Choices

- `assets/templates/default-general-common-reviewer.tex`: General option for a full TeX response with shared concerns.
- `assets/templates/reviewer-specific-response.tex`: Use when the venue expects responses organized by reviewer or each reviewer has distinct concerns.
- `assets/templates/compact-response.tex`: Use when there is a strict word or character budget.
- `assets/templates/ac-focused-response.tex`: Use when AC/meta-review concerns, global misunderstanding, or one decisive issue dominates.

## Available TeX Features

The templates provide optional building blocks:

- reviewer color macros,
- concise reviewer quote blocks,
- direct answer blocks,
- evidence blocks with line/table/figure references,
- common-concern merging,
- self-contained acronyms and experimental settings,
- limitation language for actual material boundaries.

## Filling Rules

1. Replace reviewer labels with the actual reviewer IDs used by the venue.
2. Quote only the core concern when a quote helps attribution; otherwise identify or summarize it accurately.
3. Put the direct answer before background.
4. Use bold emphasis only for decisive answers, evidence, and limitations.
5. Cite paper locations such as Section, Table, Figure, Appendix, or line number when available.
6. Include newly completed analyses or results in the rebuttal text instead of only promising them.
7. Keep reviewer-specific answers short when a common concern already answers the main issue.
8. Remove unused placeholders, example concerns, and optional change/limitation blocks. Preserve real negative evidence and unresolved concerns; do not invent praise, agreement, completed analyses, or revision promises to fill the template.
