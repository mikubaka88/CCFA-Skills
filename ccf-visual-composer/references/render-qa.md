# Render And Existing-Source QA

Inspect the actual requested output at its final paper/display size. Reuse unchanged checks; a local edit checks its region and affected dependencies, while a shared font, scale or layout change warrants broader coverage. Scientific fidelity and visual quality belong to one integrated inspection, not separate reports or a mandatory extra reviewer.

## Scientific Fidelity

- Values, precision, units, sample sizes, uncertainty and metric direction match the supplied data. Missing values and exact zeros retain their meanings; invalid probabilities/correlations are resolved rather than silently clamped.
- Related views match subjects/categories by stable IDs and intended order. Colors, legends and shared scales encode the same meanings; distinct units or independently normalized quantities are clear.
- Required method objects, actual source-to-target paths, directions, branches and train/inference boundaries match the source. A nearby object is not necessarily connected. Preserve labels, indices, equations and canonical acronyms without invented expansions.
- Scientific images retain aspect ratios, crop/contrast meaning, scale bars and actual observations. Conceptual illustrations do not impersonate measurements. Reused external assets keep their individual licenses and required credits.
- For a numerical reference reconstruction, compare the complete encoding inventory with the render: marks, transforms/colorbar, thresholds, named summaries, observations, provided intervals, labels and legend. A median–P90 box/P99 whisker/P95 marker is not an ordinary IQR box, 1.5-IQR whisker or mean. Occupancy and weighted share keep their respective denominators; series keep actual observation times.
- After an image edit in a mixed figure, compare the quantitative layer with its original code-generated export. Repair a changed measurement from that source rather than accepting a visually plausible replacement.

## Visual Quality

Inspect both the overall reading path and the final-size labels/objects. Check glyphs, equations, clipping, overlaps, legend coverage, readable type, necessary content and compactness. Preserve the selected template's composition and requested style. Remove duplicate titles/legends and wasted margins before shrinking type or adding panels.

Align actual data rectangles and corresponding crops despite unequal outer label margins; preserve fixed spatial aspect ratios. Keep scientific diagrams' real branches and merges clear, with short connections and coherent objects. Emphasize important content instead of decorative banners, generic cards or prose. Local breathing room and real plotting whitespace remain useful; an unused area is not a reason to fabricate content.

Keep Times New Roman or selected Comic Sans MS unless overridden. Key titles, legends, axes/ticks and colorbar text are bold with a readable hierarchy; subordinate method text is not equally emphasized. Bar/box/whisker/cap outlines are substantial darker shades paired with their fills; density bins, heatmap cells and dense points keep their own treatment. Check actual final physical sizes in code output and embedding. A raster's appearance cannot prove font identity or exact geometry.

The chosen color map remains stable and legible in grayscale/color-vision checks. A design preset is a suggestion, not an official venue rule. Numeric export audits can detect bounds/glyph issues, but do not certify every overlap, scientific definition or aesthetic choice. Inspect the actual image.

## Existing Source Edits And Raster Placement

For a requested local edit, use the current image/source and preserve manual changes. Raster editing uses the host image workflow; an actual existing SVG/PPTX/code source may receive authorized local edits. Resolve the target from its real object/group ID where available; screenshot annotations are location hints. Preserve meaning, move attached endpoints when editing an existing object, refresh requested exports and inspect changed dependencies. This is not permission to trace a raster or reconstruct a new diagram as shapes.

A new/redrawn diagram uses the mandatory P → G0 → G1 image workflow. Place its approved PNG into a requested PPTX/PDF at its proper aspect ratio and resolution. It remains a raster with movable/croppable placement, not native editable labels/modules. Existing native objects retain the editability they actually had. Do not run auto-trace or raster/SVG-to-PPT reconstruction. Explicit numerical SVG/PDF export is separate and preserves real values/text/objects where supported.

Render requested placement/export to check clipping, resolution, transparency, legibility and aspect ratio. Separately requested PNG assets need clean alpha edges and correct recognition; generating a full method figure does not require a separate icon pack or asset-generation pass.

## UTF-8 And Glyphs

Check source encoding separately from font coverage. Inspect actual Chinese, minus signs, Greek letters and superscripts, including PDF extraction/native text when applicable. Use a compatible installed CJK/math fallback rather than empty boxes or suppressed warnings. Changing an encoding label cannot fix a missing glyph or PDF font mapping.

Decode a native tool's diagnostic bytes using its actual encoding; some Windows tools emit GBK logs although figure text is correct. Confirm against known text rather than blanket-converting logs or rewriting valid inputs. A readable warning still needs its own assessment.

## Bounded Repair And Handoffs

Use one current preview and source record in the established artifact directory. Persist only unresolved or decision-relevant findings needed for continuation, reusing an existing record. Do not emit a screenshot/report per checklist item. A prompt-only operation is not a generated or refined image.

Repair an observed defect and inspect affected content. Repeated failures need a changed representation/instruction rather than blind nudges; after the required G1 refinement is complete, a satisfactory figure does not need further regeneration. Numerical figures retain the selected specification unless the data/question or user request warrants a change. New diagrams do not fall back to vector authoring.

Route a concrete missing dependency to its owner while continuing unaffected work: experiment designer for unsupported/missing measurements, integrity auditor for claim/number mismatch, paper writer for authorized prose/caption changes, and submission checker for final venue/package requirements. An issue count alone does not justify stopping or expanding the task.
