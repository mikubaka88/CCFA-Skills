# Humanization v1 相对原版的修改报告

日期：2026-11-26。当前改动基于上游 `main` 提交 `e26645445465a695e5d39f28a4aa02632293b4ee`；下文两轮行为实验比较冻结的本地原版与历史候选 v1。

用户已选用已测候选 v1。本次将其核心规则移入最新上游：先给答复，再说明依据；删去无信息的防御铺垫，同时保留事实、必要否定、负结果和真实不确定性。实验结论仍按各轮原定判据记录。

本次 PR 修改 `ccf-humanization/SKILL.md` 与 `ccf-humanization/references/humanization-policy.md`，新增本报告 `docs/HUMANIZATION_V1_CHANGE_REPORT.zh-CN.md`。技能名字、YAML 描述与元数据、调用入口和 Humanization → Common → 专业技能的预检顺序沿用上游，其他 17 个技能及共享规则保持原版。`v1` 标识历史候选，技能名仍为 `ccf-humanization`。

PR 来源为 `Jimmy-Dan/CCFA-Skills:codex/humanization-directness`，目标为 `mikubaka88/CCFA-Skills:main`。改动从上游当前提交直接建立，保留其精简入口、按需加载、写作范例、段落重点和无默认数值配额的破折号规则。两份规则文件按最新结构做语义整合，与历史已测候选的文件内容有所区别；下文成绩对应冻结的实验环境，本次集成尚未重跑行为对照或桌面验收。

原版已经要求删除空洞保证、想象中的审稿质疑、重复警告和多重弱化，保留负结果、假设、引用、数字及有依据的不确定性；也已经区分探索、计划与已报告结果。v1 延续这些能力，将分散原则写成更容易逐句执行的决策。

| 位置 | 原版已有要求 | v1 的具体改法 |
| --- | --- | --- |

必要否定和负结果本身就是信息。例如，未部署、未完成、未支持某项推断、某条件下性能下降，都应保留。`not`、`only`、`may` 等词不作机械禁词；实际技术差异、逐字引用和强制披露也继续保留。真正的不确定性需要写清对象及证据缺口，不能通过删除限定把“提示”改成“证明”。普通预检仍不额外生成报告、警告文件或代理，专业技能的职责和授权边界不变。

两轮均使用独立匿名上下文的模型辅助评分，尚无人工复核或人工 gold 标签。D 表示对话中出现空洞防御，H 表示出现实质事实错误，R 为每段对话适用必要信息保留比例的平均值，T 表示任务完成。联合可用要求记录有效、D/H 均为零、必要信息全部保留且任务完成。R 的平均值不是将所有信息项合并后的总体比例。

两轮使用相同的描述性保留门槛：D/H 至少一项下降、另一项不升，平均 R 与完成 T 不降，且没有新增严重编造。该门槛用于开发筛选，不提供统计显著性的确认。

第二轮主辅助评分达到描述性门槛（`descriptive_gate_met=true`），但 D 的全部差异来自 H07 原版的唯一事件：主评分将一段主动解释未要求的投稿合规检查的文字计为空洞防御。另一个全新匿名上下文仅收到相同材料包和冻结 D 定义，未获知主评分、版本映射或技能规则；其将两版 D 均判为零。

主评分保持原样，同时公开独立判断。仅将 H07 的 D 替换为独立判断后，原版与候选均为 0/10，保留门槛**未通过**（`descriptive_gate_using_independent_H07_D_judgments=false`），H/R/T 等主评分不变。因此，第二轮防御改善的判断依赖这一有分歧的事件，尚不稳定。独立复核同样属于模型辅助判断。

R 的差异还受到冻结评分口径影响。例如，H01 候选保留了 2% 与 2.8% 的端点，却因未明说增加 0.8 个百分点而扣分；这不是计算错误。对提案状态、统计证据边界、原文及 DOI 核验状态是否明确复述，也存在评分歧义。候选在第二轮并非逐题占优，两版在 H08 均有必要信息扣分，不能将所有 R 差异都解释为实质事实丢失。

两轮的 H 均为零，**没有幻觉下降的证据**；零次观察也不能证明以后不会出错。两版共同继承宿主已有的直接表达与事实准确要求，可能限制原版的可改善空间。两批均为小规模开发测试，第二轮按已知薄弱点构造，每版每题仅一次；现有记录支持描述本批观察，不能宣称普遍优势或统计显著改善。另行约定的 **12 道新来源桌面验收尚未进行**，第二轮压力题不替代该验收。
