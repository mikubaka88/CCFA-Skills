# Humanization v1 相对原版的修改报告

日期：2026-11-26。当前改动基于上游 `main` 提交 `e26645445465a695e5d39f28a4aa02632293b4ee`；下文两轮行为实验比较冻结的本地原版与历史候选 v1。

用户已选用已测候选 v1。本次将其核心规则移入最新上游：先给答复，再说明依据；删去无信息的防御铺垫，同时保留事实、必要否定、负结果和真实不确定性。

本次 PR 修改 `ccf-humanization/SKILL.md` 与 `ccf-humanization/references/humanization-policy.md`，新增本报告 `docs/HUMANIZATION_V1_CHANGE_REPORT.zh-CN.md`。技能名字、YAML 描述与元数据、调用入口和 Humanization → Common → 专业技能的预检顺序沿用上游，其他 17 个技能及共享规则保持原版。`v1` 标识历史候选，技能名仍为 `ccf-humanization`。

PR 来源为 `Jimmy-Dan/CCFA-Skills:codex/humanization-directness`，目标为 `mikubaka88/CCFA-Skills:main`。改动从上游当前提交直接建立，保留其精简入口、按需加载、写作范例、段落重点和无默认数值配额的破折号规则。两份规则文件按最新结构做语义整合，与历史已测候选的文件内容有所区别；下文成绩对应冻结的实验环境，本次集成尚未重跑行为对照或桌面验收。

原版已经要求删除空洞保证、想象中的审稿质疑、重复警告和多重弱化，保留负结果、假设、引用、数字及有依据的不确定性；也已经区分探索、计划与已报告结果。v1 延续这些能力，将分散原则写成更容易逐句执行的决策。
